## 🎯 Τι θα φτιάξουμε;

Μια **AI-powered εφαρμογή** που θα "διαβάζει" το πρωινό mood μας καθώς φτάνουμε στο γραφείο — και θα κρατάει σκορ ανά πλευρά!

```
        ┌─────────────────────────────────────┐
        │                                     │
        │   👥👥👥            👥👥👥          │
        │   👥👥👥            👥👥👥          │
        │                                     │
        │   🎅 LEFT            RIGHT 🦌       │
        │                                     │
        │               📷                    │
        │            CAMERA                   │
        │               ↓                     │
        └────────[ ENTRANCE ]─────────────────┘
```

**Το concept:**

- ☀️ Κάθε πρωί **08:00 - 11:00** η κάμερα μετράει το mood σου καθώς φτάνεις.
- ⬅️➡️ Ανάλογα με το που κάθεσαι, το mood σου μπαίνει στο σκορ της πλευράς σου.
- 🏆 Στις **11:00** κλείνει η μέτρηση και ανακοινώνεται ο νικητής της ημέρας!
- 📊 Weekly standings & streaks

## 🛠️ Technical Challenge

**Core Features (MVP):**

- 📷 Real-time mood detection (08:00 - 11:00)
- ⬅️➡️ Direction tracking (Left vs Right assignment)
- 🖥️ Live dashboard με scores
- 📧 Automated results email στις 11:00
- 📊 Historical data & weekly standings

- ⏱️ Countdown timer στο dashboard

- 🏅 Achievements ("Early Bird" - check-in πριν τις 08:30)
- 📱 Slack/Teams notification στις 11:00
- 🎵 Morning playlist based on current mood
